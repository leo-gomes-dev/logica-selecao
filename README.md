# Treino de Lógica - Uniformes

Projeto didático para praticar condicionais e operadores lógicos com uma simulação de uniformes de futebol.

## Acessar o projeto original

[Abrir logica-selecao no GitHub](https://github.com/leo-gomes-dev/logica-selecao)

## Fazer fork

1. Acesse a página do [projeto no GitHub](https://github.com/leo-gomes-dev/logica-selecao).
2. Clique em **Fork** e escolha sua conta.
3. Clone o fork, substituindo `SEU-USUARIO` pelo seu nome de usuário:

   ```bash
   git clone https://github.com/SEU-USUARIO/logica-selecao.git
   cd logica-selecao
   ```

4. Abra a pasta no editor ou abra `index.html` no navegador. O projeto não precisa de dependências nem de etapa de compilação.
5. Depois de fazer alterações, envie-as para seu fork:

   ```bash
   git add .
   git commit -m "Descreva suas alterações"
   git push
   ```

## Como funciona

- Escolha os times e as cores dos uniformes principal e reserva.
- Clique em **Verificar Uniformes**.
- Se os uniformes principais forem iguais, o time visitante usa o uniforme reserva.
- A cor das camisas acompanha as seleções feitas.

## Arquivos

- `index.html`: estrutura da página e campos do formulário.
- `style.css`: estilos e layout.
- `script.js`: lógica de comparação e atualização dos uniformes.
